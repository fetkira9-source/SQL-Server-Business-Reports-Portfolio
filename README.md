# SQL Server Business Reports Portfolio

Welcome to my SQL Server data analysis and reporting portfolio! This repository features real-world database solutions designed to transform operational data into strategic business insights, focusing on commercial auditing, inventory control, and post-sales management.

## 🛠️ Tech Stack & SQL Concepts
* **Database Engine:** T-SQL / Microsoft SQL Server
* **Key Skills:** Complex JOINs, Subqueries, Aggregations (GROUP BY), Performance Optimization, and ERP Data Structure Mapping.

---

## 📊 Business Reports Included

### 1. Sales Performance Report (`sales_performance_report.sql`)
* **Business Objective:** Analyze sales performance and audit dynamic pricing strategies across high-volume inventories.
* **Problem Solved:** Connects product costs with active selling prices to calculate real profit margins, helping teams track applied discounts and detect pricing discrepancies at the sales order level.

### 2. Warranty Management Report (`warranty_management_report.sql`)
* **Business Objective:** Monitor product warranties, technical support cases, and return inventory.
* **Problem Solved:** Centralizes post-sales operational metrics to identify product lines with higher incident rates and track specific stock movements caused by technical defects.

## 🚀 How to Use This Repository
Each `.sql` file contains clean, production-ready scripts designed for SQL Server Management Studio (SSMS). All queries include internal documentation and comments to explain the business logic and table relationships.
